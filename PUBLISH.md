# ReleaseLens setup

Clone this public repository:

```bash
git clone https://github.com/alf1ei/release-lens.git
cd release-lens
npm install
cp .env.example .env.local
npm run dev
```

Requires Node.js 20.9+. Open http://localhost:3000 and click Load demo. For checks, run `npm run typecheck`, `npm test`, `npm run lint`, and `npm run build`.
